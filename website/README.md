# AIxOrigin 宣传官网

为 **AIxOrigin · 自然灾害应急自组网** 项目制作的全滚动动画宣传页。

## 预览

```bash
# 任意静态服务器即可，例如：
python -m http.server 8080 -d website
# 浏览器打开 http://localhost:8080/
```

纯 HTML / CSS / Vanilla JS，**零外部依赖**（无 CDN、无构建步骤），
可直接放到 GitHub Pages / 任意静态托管。

## 目录

```
website/
├── index.html          # 单页滚动式官网（8 屏）
└── assets/
    ├── css/style.css   # 深色应急控制台风格设计系统
    └── js/main.js      # 滚动动效 / Canvas 自组网动画 / 交互演示
```

## 交互与动画

> 所有滚动动画都会在**每次滑入对应屏幕时重新播放**：内容离开视口后回到
> 初始状态（淡出 / 归零 / 复位），再次进入时从头播一遍。

- **Hero**：Canvas 动态“星座 / 节点网”，光标靠近产生斥力；标题逐字上浮
- **核心链路**：四步链路卡片滚动渐显
- **决策引擎**：危险指数仪表盘扫过视口后从 0 动画到 97、存活率 25%
- **离网 Mesh**：可交互 Canvas 拓扑 —— **点击任意节点**触发一次“广播洪泛”，
  观察报文沿一跳一跳的路径扩散；节点也可拖拽
- **随身终端**：可切换 **安全 / 预警 / 危险** 的 OLED 像素屏还原（危险时反白闪烁）
- **水位节点**：视口进入后水位从干燥涨到 1cm，BLE 广播指示点亮
- **Android App**：地图灾情多边形 / AI 逃生气泡逐字打字（DeepSeek 规划文案）
- 全文支持 `prefers-reduced-motion` 无障碍降级；无 JS 时也有 `noscript` 兜底
