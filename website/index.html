THE LOOP · 01

从灾害发生，到指令抵达 —— 全程离网

不依赖路由器、基站与公网。任何一台节点发现险情，整个 Mesh 与身边的手机立刻进入避险状态。

STEP 1 · INPUT
⚠

灾害输入

板载按键短按切换 安全 / 预警 / 危险，长按立即广播；串口命令注入地震、暴雨、泥石流等信号，或由水位节点自动上报积水。

STEP 2 · ENGINE
◎

边缘决策引擎

每次状态变化即时重算危险指数 0–100 与存活率分级 —— L0 95% · L1 70% · L2 25%，在设备本地完成，无需上云。

STEP 3 · RADIO
⌁

ESP-NOW 离网广播

定长结构体约 30B 封包广播，CRC8 + 序号去重，支持中继转发扩展覆盖；状态变更即时发出，另配 1s 心跳。

STEP 4 · GUIDE
➤

实时逃生指引

监测节点 OLED 就地亮起等级与撤离方向，App 全屏告警、振动与语音导航 —— 现场与手机同步响应。

验收口径：状态同步 < 50ms · 心跳 1s · 报文结构体 packed，不走 JSON 以省无线开销

EDGE ENGINE · 02

危险，在边缘被算出来

决策不出设备 —— 单芯片完成风险计算，把最珍贵的几秒钟留给逃生。

  • 01

    危险指数 0–100

    综合灾害类型与强度实时重算，OLED 以动画条呈现，数值一目了然。

  • 02

    存活率三级分级

    L0 = 95% · L1 = 70% · L2 = 25%，与 Android App 侧 RiskEngine 基线完全对齐。

  • 03

    多灾种输入

    支持地震 / 暴雨山洪 / 泥石流滑坡 / 低洼积水等灾种信号驱动。

ESP-NOW MESH · 03

没有路由器，网络反而更顽强

ESP-NOW 让每一块板子既是端点、又是中继。拖动下面的节点看看报文如何跳转扩散。

哨兵 Node_A 中继 Node_B 监测显示 Node_C App / 网关
  • ⌁

    同频互联，一跳扩散

    定长 packed 结构体广播，中继节点收到即 hops+1 转发，扩大应急覆盖范围。

  • ⛨

    CRC8 + 序号去重

    脏帧丢弃、重复帧去重，多跳转发下数据依旧干净可靠。

  • ◷

    状态即时 + 1s 心跳

    险情变化立即广播；心跳维持全网节点在线视图。

  • ⇄

    手机双向桥接

    App 经 BLE(Nordic UART) 或 WiFi UDP 接入 mesh，并回传手机 GPS / 一键 SOS。

NODE OLED · 04

监测节点的“就地告警屏”

人只带手机；这块 128×64 单色 OLED 装在监测节点上 —— 亮度、反白与闪烁节奏，在黑白屏上分得清 绿 / 黄 / 红。

  • 大字危险等级 + 自绘大数字存活率 + 动画指数条，现场一眼读懂
  • 危险时整屏反白 350ms 闪烁，可同步外接告警灯 / 蜂鸣器
  • Mesh 中继的远端险情也会就地亮起，让告警覆盖节点周边
  • 三态屏保 安全 / 预警 / 危险 可切换，纯黑白也能表达色彩语义

GET STARTED · 07

从仓库到板子，三步跑起来

01

Arduino IDE

安装 esp32 by Espressif 开发板包与 U8g2 库，打开 firmware/AIxNode/AIxNode.ino，选板型 ESP32S3 Dev Module 后上传。

firmware/AIxNode/AIxNode.ino
02

PlatformIO

VS Code + PlatformIO 打开仓库根目录，编译默认 Node_A 角色；切换注释的 nodeB / nodeC env 可烧录中继与监测显示节点。

pio run -t upload
03

Android App

JDK 17 + Android Studio 打开 android/，在 gradle.properties 填入高德 Key，运行真机即可体验「模拟灾情 Lv2」。

./gradlew assembleDebug
