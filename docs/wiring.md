# 接线说明 (ESP32-S3 + OLED)

以 **ESP32-S3-DevKitC-1**（或同类 S3 核心板）为例。默认引脚全部在
`AIxNode.ino` 顶部 `用户配置区`，改接线后同步改宏即可。

## 1. OLED 屏幕 (1.54 寸 / 2.42 寸, 4 线 SPI)

| OLED | ESP32-S3 | 说明 |
|---|---|---|
| VCC / VDD | **3V3** | 多数模块带稳压可接 5V；**以模块丝印为准**，推荐 3V3 |
| GND | **GND** | 共地 |
| SCK / SCL / CLK | **GPIO12** | 时钟线 |
| MOSI / SDA / DIN | **GPIO11** | 主机输出数据线 |
| MISO | **GPIO13** | 从机输入（OLED 一般不回读，但总线需接好） |
| CS | **GPIO10** | 片选 |
| DC / RS | **GPIO6** | 数据 / 命令选择 |
| RES / RST | **GPIO7** | 复位 |

> ESP32-S3-DevKitC-1 的默认 SPI 即 SCK=12 / MOSI=11 / MISO=13（`SS=10` 已作 CS），
> 固件默认值无需改。若用其它 S3 板子，请以该板默认/你实际接线为准，并修改
> `OLED_SCK` / `OLED_MOSI` / `OLED_MISO` / `OLED_CS` / `OLED_DC` / `OLED_RES`。

### 屏幕控制器型号确认
同样 128x64 OLED 常见三种控制器，固件通过 `OLED_MODEL` 切换 U8g2 驱动：

| 型号 | `OLED_MODEL` | 常见尺寸 |
|---|---|---|
| SSD1306 | `1`(代码默认) | 0.96" / 1.54" |
| SH1106 | `2` | 部分 2.42" |
| SSD1309 | `3`(platformio.ini 已设为 3) | 部分 2.42" |

**拿到屏幕先看背板 IC 丝印**（SSD1306 / SH1106 / SSD1309）。
若显示乱码/黑屏，优先：① 换 `OLED_MODEL`；② 确认 SPI 引脚（`OLED_SCK/MOSI/CS/DC/RES`）
与屏幕丝印一致。SPI 屏通常无需改地址。

## 2. 按键 (板载 BOOT / 外接按键)

| 按键 | ESP32-S3 |
|---|---|
| 板载 BOOT 键 | GPIO0（已接上拉，低电平有效）→ **无需接线** |
| 外接按键(可选) | 一端 GPIO0、一端 GND（固件已启用内部上拉，可不接外部电阻） |

> ⚠️ 上电/复位的瞬间**不要按住 BOOT**，否则进入下载模式而不是运行固件。
> 长按(≥0.8s)=立即广播；短按=切换 安全→预警→危险。

## 3. 可选告警 LED / 有源蜂鸣器

| 器件 | ESP32-S3 |
|---|---|
| LED 阳极 / 蜂鸣器信号脚 | 任意空闲 GPIO，如 **GPIO4** |
| LED 阴极 | GND(串 220Ω~1kΩ 限流电阻) |

在固件里把 `ALARM_PIN` 改成该引脚（默认 `-1` 关闭）。高危时随屏幕反白闪烁节奏输出高电平。

## 4. GPS 模块（穿戴端定位，可选）

给**随身逃生终端(Node_C)** 外接 GPS，让它知道自己真实坐标并广播给全网。
常见模块：**NEO-6M / ATGM336H(北斗+GPS) / BN-220**，均 3.3V UART、9600 波特、NMEA 输出。

| GPS 模块 | ESP32-S3 | 说明 |
|---|---|---|
| VCC | **3V3** | 个别模块标 5V，仍按丝印/模块说明接 |
| GND | **GND** | 共地（务必与板子共地） |
| TX | **GPIO18**（`GPS_RX_PIN`） | 模块发送 → ESP32 接收 |
| RX | **GPIO17**（`GPS_TX_PIN`） | ESP32 发送 → 模块接收（只读定位可悬空） |

> 固件 `GPS_ENABLE` 默认 `1`；非穿戴端角色可改 `0` 关掉。改接线后同步改
> `GPS_RX_PIN` / `GPS_TX_PIN` / `GPS_BAUD`。
> 上电后串口打印 `[GPS] init ...`，拿到定位后打印 `[GPS] fix acquired lat=... lon=...`。

## 5. 电源与共地
- 所有节点用充电宝/电脑 USB 分别供电即可（无需共地，ESP-NOW 是无线通信）。
- 演示距离较远时，OLED 与 ESP32-S3 之间导线尽量短，SPI 线长 <20cm 为宜（SCK/MOSI 尤其要短且共地）。

## 6. 常见问题排查
| 现象 | 排查 |
|---|---|
| 串口无输出 | 确认波特率 115200；确认烧录时选了正确串口 |
| 屏幕不亮/花屏 | SPI 引脚（`OLED_SCK/MOSI/CS/DC/RES`）、`OLED_MODEL` |
| GPS 无定位(S0) | 室外空旷处搜星；确认模块 TX→GPIO18、共地；串口看有无 `[GPS] fix`；换 `GPS_BAUD` |
| 两块板互相收不到 | 确认都在信道 1、都没连 WiFi；近距离测试；分别看串口 `[TX]/[RX]` 日志 |
| 按键无反应 | 确认用的是 GPIO0；上电后再按；是否被烧录时序占用 |
